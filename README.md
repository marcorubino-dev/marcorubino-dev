## How I approach technical issues

1. **Observe:** reproduce the behavior and collect relevant evidence.
2. **Isolate:** narrow down the responsible component or interaction.
3. **Diagnose:** test hypotheses instead of relying on assumptions.
4. **Fix:** apply the smallest appropriate intervention.
5. **Verify:** confirm the expected behavior and check for regressions.

I value clear findings, reviewable changes, and honest technical reporting. When an issue requires more investigation, I communicate what has been tested, what has been ruled out, and what remains uncertain.
